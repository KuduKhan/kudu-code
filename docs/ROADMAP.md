# KUDU CODE engineering roadmap

Version numbers are engineering milestones, **not** assurances of production readiness.

- v0.1: FastAPI foundation, SQLite and secure local API.
- v0.2: Projects, validated GitHub repository references and workspace registration.
- v0.3: Persistent tasks and deterministic role-based task planning.
- v0.4: Optional model-assisted plans and proposed file changes.
- v0.5: Workspace and Git version-control integration.
- v0.6: Approval gates, isolated Docker tests, commit and push controls.
- v0.7: Read-only provider status integration and audit events.
- v0.8: Premium responsive command-center interface.
- v0.9: Automated tests, lint/build gating and CI.
- v1.0: Production-hardening design, API docs, policy baseline and operator guide.

Not yet implemented: multi-tenant access, durable distributed queue, full MCP client, model router, cloud VM isolation, automatic remediation, full release pipeline, remote production operator. These remain distinct post-MVP deliverables.
